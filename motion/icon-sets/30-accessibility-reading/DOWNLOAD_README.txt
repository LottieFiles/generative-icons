ACCESSIBILITY & READING — Generative Animated Icons by LottieFiles

10 animated vector icons: Accessibility, Wheelchair access, Hearing assistance, High contrast, Reduced motion, Text size, Keyboard, Keyboard shortcuts, Focus indicator, Reading mode.
Light and Strong motion. Outline (1.5 / 2 / 2.5 weights), Solid and Duotone styles. Light and dark themes.
32 x 32 grid, 60 fps.

Each .lottie contains every action for its icon; the filename selects the initial action. Each .json contains one native action (10 in this set).
Theme slots: color.primary; style.outline.light / regular / bold; style.solid; style.tint (Duotone at 18%); style.outline.width (stroke-width token: the Regular outline at any weight).
Stateful icons include explicit reverse or reset actions.

The source/ folder holds the editable geometry and motion. Rebuilding native files needs the Engine exporter (see docs/development.md in the repository).

Browse: run `npm run dev` in the repository and open /icons/01/#category-accessibility-reading
