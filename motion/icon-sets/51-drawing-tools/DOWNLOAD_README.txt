DRAWING & DESIGN TOOLS — Generative Icons by LottieFiles

20 animated vector icons: Pen tool, Brush, Eraser, Corner radius, Line tool, Rectangle tool, Ellipse tool, Polygon tool, Fill bucket, Eyedropper, Group objects, Align objects, Magic wand, Lasso select, Transform tool, Rotate tool, Mirror tool, Snap to grid, Ruler guides, Scissors.
Light and Strong motion. Outline (1.5 / 2 / 2.5 weights), Solid and Duotone styles. Light and dark themes.
32 x 32 grid, 60 fps.

Each .lottie contains every action for its icon; the filename selects the initial action. Each .json contains one native action (60 in this set).
Theme slots: color.primary; style.outline.light / regular / bold; style.solid; style.tint (Duotone at 18%); style.outline.width (stroke-width token: the Regular outline at any weight).
Stateful icons include explicit reverse or reset actions.

The source/ folder holds the editable geometry and motion. Rebuilding native files needs the Engine exporter (see docs/development.md in the repository).

Browse: run `npm run dev` in the repository and open /icons/01/#category-drawing-tools
