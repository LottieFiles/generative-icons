# Teamwork native review

Codex reviewed all 40 new icons after actual Claude Code first designs and revisions. The existing 341-icon artwork was protected. The per-icon decisions, accepted proposal paths, meaningful motion measurements and current package hashes are in `../../library/design-reviews/teamwork/icon-review-ledger.json`.

The review used actual native 24/32 px playback at 1x for both profiles (160 completion records), four equal-elapsed-time sheets, and four context sheets in each theme. Context samples include true 16/20/24/32/48 px rendering and Outline weights, Solid and Duotone. Two further sheets compare every new icon to two current family neighbors at 32 px. The final gallery screenshot shows the same page and category used for delivery.

The native sheets retain the same stroke language, round joins and clear openings. Strong changes the main action: greater physical travel where the object supports it, or a more decisive complete draw where both profiles must retain the same result. One generic pulse was not applied across the set. Pointers separate, badges swing, gates open, cloth waves, a divider scrubs, stamps strike and written outputs remain written.

Native review led to four final timing changes: Sprint cycle now uses a quiet 120-degree Light index against a full Strong turn; Task dependency and Shared goal draw their primary strokes sooner; Reopen thread no longer pauses on a short intermediate stub. Current captures supersede `captures/initial-native/` for these icons. The initial failed/incomplete verification attempts remain recorded.

Construction corrections include hidden card terminals, delayed arrowheads and pupils, a second collaborator that appears only after room opens, full cursor return clearance, and an opaque geometric reset for connected output paths. See `MEASURED_CORRECTIONS.md` and the dated Teamwork entry in `docs/design-principles.md` for exact changes and limits.

The full-frame native check covers all 130 actions at 24/32/48/192 px, seven style/weight variants and both themes: 1,048,320 frame samples. Source and exported geometry checks cover 62 painted gap rules and 18 opaque/joint rules. Intentional stamp and glass contacts were reviewed visually; these checks do not claim a general collision solver. Sprint declares its real threefold symmetry and uses the existing renderer boundary rule without changing the tolerance.

All-frame checks are technical evidence. The sampled visual review is a separate Codex judgment, not independent motion-director or user approval. Exact served ZIP and asset evidence is recorded by `verify-delivery.py` in `archive-verification.json` after packaging.
