MOTION DESIGN — Generative Animated Icons by LottieFiles

20 animated vector icons: Timeline, Add keyframe, Remove keyframe, Auto keyframe, Keyframe easing, Graph editor, Bezier handles, Motion path, Anchor point, Layer stack, Parent layers, Precompose, Trim layer, Split layer, Time stretch, Onion skin, Shape morph, Mask path, Track matte, Render queue.
Light and Strong motion. Outline (1.5 / 2 / 2.5 weights), Solid and Duotone styles. Light and dark themes.
32 x 32 grid, 60 fps.

Each .lottie contains every action for its icon; the filename selects the initial action. Each .json contains one native action (20 in this set).
Theme slots: color.primary; style.outline.light / regular / bold; style.solid; style.tint (Duotone at 18%).
Stateful icons include explicit reverse or reset actions.

The source/ folder holds the editable geometry and motion. Rebuilding native files needs the Engine exporter (see docs/development.md in the repository).

Browse: run `npm run dev` in the repository and open /icons/01/#category-motion-design
