FIVE USEFUL ACTIONS — Generative Animated Icons by LottieFiles

5 animated vector icons: A turn toward attention., Confirmation that stays., A deliberate adjustment., A latch with intent., Open the folder..
Light and Strong motion. Outline (1.5 / 2 / 2.5 weights), Solid and Duotone styles. Light and dark themes.
32 x 32 grid, 60 fps.

Each .lottie contains every action for its icon; the filename selects the initial action. Each .json contains one native action (5 in this set).
Theme slots: color.primary; style.outline.light / regular / bold; style.solid; style.tint (Duotone at 18%).
Stateful icons include explicit reverse or reset actions.

The source/ folder holds the editable geometry and motion. Rebuilding native files needs the Engine exporter (see docs/development.md in the repository).

Browse: run `npm run dev` in the repository and open /icons/01/#category-essentials
