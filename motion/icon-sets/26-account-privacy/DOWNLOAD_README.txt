ACCOUNT & PRIVACY — Generative Animated Icons by LottieFiles

12 animated vector icons: Sign in / out, Switch account, ID card, Password, Passkey, Fingerprint, Face authentication, Two-factor code, Recovery codes, Private browsing, Cookie preferences, Block user.
Light and Strong motion. Outline (1.5 / 2 / 2.5 weights), Solid and Duotone styles. Light and dark themes.
32 x 32 grid, 60 fps.

Each .lottie contains every action for its icon; the filename selects the initial action. Each .json contains one native action (12 in this set).
Theme slots: color.primary; style.outline.light / regular / bold; style.solid; style.tint (Duotone at 18%).
Stateful icons include explicit reverse or reset actions.

The source/ folder holds the editable geometry and motion. Rebuilding native files needs the Engine exporter (see docs/development.md in the repository).

Browse: run `npm run dev` in the repository and open /icons/01/#category-account-privacy
