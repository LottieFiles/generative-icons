# Agent instructions

Generative Animated Icons: native Lottie icons with Light/Strong motion and editable source. Read this file, then the source you are about to change.

## Repo map

| Path | What lives there |
| --- | --- |
| `motion/icon-sets/NN-name/` | Editable icon source (`definitions.mjs`), builder, set checks |
| `motion/icon-sets/library/` | Family contract, context search, preflight, shared helpers |
| `prototype/icons/catalog.json` | Registered sets, in gallery order |
| `prototype/icons/NN/assets/` | Built native assets (generated by the builder) |
| `prototype/icons/01/` | Cumulative local gallery |
| `packages/` | npm packages: icons, runtime, react, cli |
| `docs/` | User, contributor and maintainer documentation |

## Commands that matter

```sh
npm ci && npm run setup                                         # install
npm run dev                                                     # gallery on :4189
node motion/icon-sets/library/generation-context.mjs --query "..." --search
npm run icons:new -- <slug> --name "<Name>"                     # scaffold a set
node motion/icon-sets/library/preflight.mjs motion/icon-sets/SET-ID
npm test && npm run check:source && npm run check:assets && npm run check:paint
```

Native build, registration and exporter setup: [creating icons](docs/creating-icons.md) and [development](docs/development.md).

## Working rules

- One coding agent performs design, authoring, review and correction; these are stages, not separate model roles. Do not invoke another model or AI CLI unless the user asks.
- Search existing meanings first and pick relevant family neighbors. Provide complete named geometry, pivots and distinct Light/Strong motion.
- Preserve existing public icon IDs and unrelated assets. Build complete sets; partial builds can truncate manifests.
- After a successful native build, register the set in `prototype/icons/catalog.json` with `npm run icons:register -- SET-ID`.
- Native export needs the Engine exporter (`CREATOR_MCP_BIN`). If it is unavailable, fail clearly, finish the source checks and say that native export is left for a maintainer.
- Inspect rendered output between revisions. Report checks you could not run; never claim a rendered review you did not do.
- Do not weaken checks to make them pass. Preserve failed evidence for diagnosis.

## Do not

- Publish packages, push tags, deploy or change repository visibility.
- Hand-edit generated files: `prototype/icons/guide/` (run `npm run docs:build`), `prototype/icons/NN/assets/` (run the set builder) or `packages/*/dist/` (run `npm run build:packages`).
- Commit `.local/`, credentials, machine-specific paths, model transcripts or planning notes.
- Change global model or agent settings.

After changing canonical instructions or docs, run `npm run docs:build` and `npm run check:docs`.
