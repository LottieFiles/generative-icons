01 / DRAW THE FAMILY

Consistent rules. Optical judgment.

Start with meaning and a complete silhouette. Match nearby icons at actual size; identical stroke numbers alone do not guarantee identical visual weight.

Outline

Keep one shared stroke width. Preserve openings at Bold. Do not scale the whole drawing to simulate weight.

Solid

Draw the intended filled silhouette. Preserve counters and join strokes inside surfaces so raster gaps cannot appear.

Duotone

Use an 18% tint only inside real enclosed surfaces. Open signals, brackets and lines stay unfilled. Do not add a background shape just to create tint.

Draw what movement reveals: the complete rim under a lid, the hinge behind a flap, and the hidden sections of a feeding page. Never use background-colored patches to hide broken geometry.

02 / GIVE IT A REASON TO MOVE

Cause → action → response → final state.

Choose fixed parts, a driver, followers and physical connections before keyframing. Hardware stays rigid. Paper feeds. Cloth bends. Every follower responds to something.

Light

One clear, quiet action. Small but readable travel, controlled response, and a useful resting state.

Strong

A visibly stronger main action: wider travel or rotation, deliberate preparation, decisive motion and visible recovery. Extra decoration or a speed change alone is not enough.

Compare both at equal elapsed time, normal speed and 24/32 px. Keep compatible endpoints for profile switching. The current family uses 60 fps and a 2.4-second timeline; continuous indicators need a deliberate periodic cycle instead of the gesture end hold.

04 / DEFINITION OF DONE

An export is the start of verification.

  • Source: finite points, stable path topology, correct pivots, attached joints, valid opacity, timing and state boundaries.
  • Paint: shared stroke values, round caps/joins and correct Duotone policy. No transform-based fake weight.
  • Native frames: inspect every changed action at 24, 32, 48 and 192 px; all supported styles, weights and both themes. Measure the real canvas size.
  • Visual review: compare the icon beside neighbors, inspect contact and settling, and watch Light/Strong at normal speed. Frame checks cannot judge timing appeal.
  • Interaction: hover, keyboard focus, touch, profile switching, loop behavior, reduced motion and the correct active-profile download.
  • Delivery: served file hashes match reviewed packages. Preserve unrelated assets. Technical checks, agent review and user approval are separate.
npm --prefix motion run verify:paint
npm --prefix motion run test:harness
